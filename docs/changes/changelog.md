# 版本更新记录

按时间倒序。已发行的版本整理自 GitHub Releases 的更新说明（与角色相关的条目已移除）；最前面一节是还没有发行的源码改动。

## 尚未发行（源码）

下面这些改动已经进了源码（部分还在工作区里、尚未提交），**没有随任何发行版发布**，想用得自己从源码构建。当前发行版是 1.3.2（2026-09-16），这些改动都是它之后才做的。

多人联机：

- 没有观战功能
- 没有对局结算页，一局打完直接回房间页
- 选房（大厅）页改版，统计块沿用 `ending.rs` 的平行四边形风格
- 「连接」页只剩下「连接」与「返回主页」两个按钮
- 暂停 / 继续的倒计时回到 3 秒
- 房间页：成绩卡去掉黑白渐变底；评级位显示真实评级（F / C / B / A / S / V）；开始按钮在不满足条件时置灰禁用，而不是直接隐藏；选谱后立即在后台下载 / 同步；顶栏尾部的按钮按文字宽度排布；去掉右侧的加粗黑线，右下渐变的亮端调亮

界面与首启：

- 新增首启向导：语言 → 登录 → 音量 → 其他设置 → 最后确认，走完才进主界面；老玩家不会重走
- 加载页动画重做：背景从右侧推入、面板左偏后淡入、封面淡入；按下「开始」时有一次全屏白闪
- 选曲页「开始」按钮改成白色平行四边形，图标等比缩小，按住时压暗
- 全屏适配：16:10 / 21:9 / 4:3 / 竖屏都能正常排版（支持范围 21:9 ~ 9:16）
- 主页背景可选：内置 `background.jpg`、`bg1.png`、`bg2.png`、`bg3.png`、`background_old.jpg` 五张（素材已放进仓库，选择界面还没做）

判定：

- Flick 对齐 Phira：不再在划动之前「预判」直接给 Perfect，必须真的划；同时补上晚按保护
