# 与 Phira 的区别

Phira-Vrenxz 是 [Phira](https://github.com/TeamFlos/phira) 的分支。谱面标准、判定和核心玩法沿用原版，改动集中在界面与一批可以自己调整的地方。下面按功能归类，内容整理自项目发布页（GitHub Releases）里的更新说明。

## 界面

- UI 比例：菜单、字体、触摸区域可以整体缩放，背景不跟着缩放
- 个人资料页改成平行四边形风格，去掉了阴影
- 主菜单与列表改成卡片式
- 暂停界面重做
- 设置页新增「自定义」栏：UI 位置、主页 UI 偏移、主题色等
- 「旧主页模式」：可以切回旧版的主页背景与音乐
- 显示分数默认打开；低分辨率下默认关闭以省性能

## 谱面

- 导出支持 .pez 格式
- 支持批量下载谱面
- 内置谱面
- 修了谱面库的闪退

## 输入与判定

- 去掉系统输入框，改成游戏内输入框
- 修了输入框无法复制粘贴的问题
- 修了 drag / flick 的键盘判定与输入法卡键

## 其它

- 修了视频播放与谱面解锁动画的闪退
- 内置 XC-SIM（需要登录）
- 去掉了 Windows 版的控制台窗口
- 从 v1.3.0 开始提供 Android 安装包

## 已经在源码里、但还没发行的改动

下面这些已经进了源码，**尚未包含在任何发行版**中，想用得自己从源码构建。

### 多人联机

- 内置 Phira-MP 客户端：房间列表与房间号加入、房主选谱、准备开局、房间内聊天，也可以连自建服务器
- 没有观战功能，也没有对局结算页：一局打完直接回房间页，可以接着再来一局
- 选房（大厅）页改版，统计块沿用 `ending.rs` 的平行四边形风格
- 「连接」页只剩下「连接」与「返回主页」两个按钮
- 暂停 / 继续的倒计时回到 3 秒

### 房间页

- 成绩卡去掉黑白渐变底
- 评级位显示真实评级（F / C / B / A / S / V）
- 开始按钮在不满足条件时置灰禁用，而不是直接隐藏
- 选谱后立即在后台下载 / 同步
- 顶栏尾部的按钮按文字宽度排布
- 去掉右侧的加粗黑线，右下渐变的亮端调亮

### 首次启动向导

- 新增首启向导，按 语言 → 登录 → 音量 → 其他设置 → 最后确认 五步走完才进主界面，版面整体靠右
- 最后一步会问是否游玩新手教程；每一步都可以前进，没有账号也能进游戏
- 老玩家不会重走：数据里已经选过语言的（`has_chosen_language`），按向导已走完处理

### 界面

- 全屏适配：21:9 到 9:16 之间的窗口比例（16:10、4:3、竖屏都算）共用同一套版面
- 加载页动画重做：背景从右侧推入，面板左偏后淡入，封面淡入；按下「开始」时有一次全屏白闪，白闪盖在最上层，等滑入完成后淡出
- 选曲页「开始」按钮改成白色平行四边形，右侧裁平并贴着屏幕边缘；图标等比缩小，按住时压暗

### 判定

- Flick 对齐 Phira：不再在划动之前「预判」直接给 Perfect，必须真的划；同时补上晚按保护

### 数据

- 旧版本数据同步：启动时检测本机有没有旧版 PhirLie / Phira-Vrenxz 的 data 目录并询问是否同步；同步过一次后不再自动提示，之后可以在 **设置 → 存储与重置 → 同步旧版本数据** 里手动同步
